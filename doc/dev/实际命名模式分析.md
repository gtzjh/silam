# SILAM项目实际命名模式分析

当前保留160个 `.f90` 源文件，历史命名仍包含以下变体：

## 实际命名模式

### 1. 标准模块命名
```
<module_name>.silam.mod.f90     # SILAM层模块（52个）
<module_name>.silja.mod.f90     # SILJA层模块（32个）
```

### 2. 允许的变体
```
<name>_v<N>.silam.mod.f90       # 带版本号
<name>_<N>.silja.mod.f90        # 带数字后缀
<name>_<detail>.silam.mod.f90   # 带详细描述
```

### 3. 特殊模块（无层次标识）
```
<name>.mod.f90                  # 其他模块（17个）
例如：
- revision.mod.f90
- silam_units.mod.f90
- chemical_setup.mod.f90
```

### 4. 允许的字符
- 小写字母
- 数字
- 下划线
- **大写字母**（在缩写中，如NH3, FAN）

### 5. 化学机制命名
```
cbm<N>(_strato)?_SOA_<Component>.f90
cbm<N>(_strato)?_SOA_interface.mod.f90
chem_dep_cbm<N>(_strato)?_SOA.mod.f90
```

## 分层依赖问题

发现真实的分层违规：
```
source_terms_bomb.silja.mod.f90  → source_terms_time_params
source_terms_volcano.silja.mod.f90 → source_terms_time_params
```

这表明`source_terms_time_params`可能应该是SILJA层基础模块，或者这两个文件应该归类为SILAM层。

## 建议

**对于新代码**：
- 遵循 `<name>.silam.mod.f90` 或 `<name>.silja.mod.f90` 格式
- 使用小写字母和下划线
- 避免数字和版本号（除非必要）

**对于现有代码**：
- 理解这些历史命名模式
- 不强制重命名（避免破坏现有依赖）
- 保持一致性
