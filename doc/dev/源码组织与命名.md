## 源代码组织规则

### 命名约定

SILAM保留历史上的三类命名。文件按实际功能归入 `src/` 子目录；目录名不代表 SILJA/SILAM 依赖层次。

#### **文件命名格式**
```
<module_name>.<library>.<type>.f90

例如：
- chemistry_manager.silam.mod.f90    # SILAM模块
- fields.silja.mod.f90                # SILJA模块  
- silam_main.f90                      # 主模型程序
```

#### **命名层次**
1. **SILJA层**（`.silja.mod.f90`）
   - 通用基础库，与具体应用无关
   - 例子：`globals.silja.mod.f90`, `fields.silja.mod.f90`
   - 历史设计定位：不依赖SILAM特定业务逻辑；现有代码有例外，见[实际命名模式分析](实际命名模式分析.md)

2. **SILAM层**（`.silam.mod.f90`）
   - 应用层模块，实现SILAM特定功能
   - 例子：`chemistry_manager.silam.mod.f90`
   - 特点：可以依赖SILJA层，包含业务逻辑

3. **程序入口**（`.f90`）
   - 主模型或测试程序
   - 例子：`silam_main.f90`, `test_modules.f90`
   - 特点：包含PROGRAM主程序

#### **化学机制文件**
已有 KPP 生成源码使用以下命名；当前分发不含生成器，仍须保留这些主模型依赖：
```
cbm5_SOA_<Component>.f90

例如：
- cbm5_SOA_Global.f90
- cbm5_SOA_Integrator.f90
- cbm5_SOA_Jacobian.f90
```

### 文件放置规则

**核心原则：生产源码按功能放在 `src/`，独立测试程序放在 `tests/`。**

```text
src/silam_main.f90                            # 主程序入口
src/core/                                    # 常量、配置、时间、运行时与并行支持
src/grid/                                    # 网格、垂直层与地理坐标
src/fields/                                  # 场数据结构与存储
src/meteo/                                   # 气象输入、缓存与派生量
src/transport/                               # 扩散调度、输送、沉降与边界条件
src/emissions/                               # 各类排放源
src/chem/                                    # 物种、化学、气溶胶与光解
src/chem/cbm5_soa/                            # CBM5 SOA机制及接口
src/chem/cbm5_strato_soa/                      # CBM5平流层SOA机制及接口
src/chem/cbm7_soa/                            # CBM7 SOA机制及接口
src/chem/cbm7_strato_soa/                      # CBM7平流层SOA机制及接口
src/diagnostics/                             # 模拟诊断量
src/io/                                      # 文件格式与输出调度
src/assimilation/                            # 同化、集合、观测与伴随支持
src/numerics/                                # 数值求解库
tests/test_modules.f90                       # 通用模块测试入口
tests/test_enkf.f90                          # EnKF测试入口
tests/test_perturb.f90                       # 扰动测试入口
```

现有文件只调整路径，保留文件名、模块名和公共接口。每个化学机制目录包含对应的 11 个 KPP 求解器及支持文件、一个 SILAM 接口和一个 `chem_dep_cbm*` 适配模块。

本地生成的 `revision.mod.f90` 和 `svndiff.mod.f90` 保留在 `src/` 根层，不提交。模块内部已有的测试辅助过程保持原接口；本次迁移仅将三个独立 `PROGRAM` 文件移入 `tests/`。

### 模块结构模板

#### SILJA模块模板
```fortran
MODULE <module_name>
  !
  ! Description:
  ! [模块功能简述]
  !
  ! Author: [姓名], FMI
  !
  ! Language: ANSI standard Fortran 90
  ! Units: SI
  !

  ! Modules used:
  USE natural_constants
  USE max_sizes_and_limits
  
  IMPLICIT NONE
  
  PRIVATE
  
  ! Public interfaces
  PUBLIC :: <public_functions>
  
  ! Module contents...
  
END MODULE <module_name>
```

#### SILAM模块模板
```fortran
module <module_name>
  !
  ! The module [功能描述]
  !
  ! Code owners: [姓名], email <firstname>.<lastname>@fmi.fi
  !
  ! Units: SI
  ! Code: ANSI FORTRAN-90 (or close to it)
  !

  use <silja_modules>
  use <silam_modules>
  
  implicit none
  
  private
  
  ! Public exports...
  
  ! Module implementation...
  
end module <module_name>
```

## 文件命名速查表

| 用途 | 命名格式 | 示例 |
|------|----------|------|
| SILAM模块 | `<name>.silam.mod.f90` | `chemistry_manager.silam.mod.f90` |
| SILJA模块 | `<name>.silja.mod.f90` | `fields.silja.mod.f90` |
| 主程序 | `<name>.f90` | `silam_main.f90` |
| 测试程序 | `<name>.f90` | `test_modules.f90` |
| 化学机制 | `cbm<N>_<detail>_<comp>.f90` | `cbm5_SOA_Integrator.f90` |
