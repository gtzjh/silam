# 项目结构与架构

[返回开发文档目录](README.md)

## 项目概况

SILAM（System for Integrated modeLling of Atmospheric coMposition）是芬兰气象研究所（FMI）开发的大气化学传输模型，用于模拟大气污染物的扩散、转化和沉降。

### 技术栈
- **语言**：Fortran（160个 `.f90` 源文件，包含本地生成的版本模块）
- **构建系统**：GNU Make
- **保留的编译配置**：GNU (gfortran)、GNU 调试及 GNU MPI
- **外部依赖**：
  - eccodes（GRIB数据格式）
  - NetCDF（科学数据IO）
  - LAPACK/BLAS（线性代数）
  - PROJ（地图投影）
  - BZip2（压缩）
- **化学机制**：保留已有的 KPP 生成源码；本分发不含生成器

### 代码规模统计
```
总源文件数：160个 .f90 文件
模块文件：101个 .mod.f90
  - SILAM模块：52个 (.silam.mod.f90)
  - SILJA模块：32个 (.silja.mod.f90)
  - 其他模块：17个
程序入口：4个（1个主模型、3个测试程序）
主模型静态 USE 依赖：157个源文件
```

## 目录结构与职责

### 核心目录

```
silam/
├── source/           # 所有Fortran源代码（160文件）
├── build/            # 构建系统和编译配置
│   ├── makefile      # 主Makefile
│   ├── options.*     # GNU及GNU MPI编译选项
│   └── makefile.*    # 子系统构建规则
├── bin/              # 可执行文件输出目录
├── obj/              # 编译中间文件（.o, .mod）
│   └── <compiler>/   # 按编译器分类
├── ini/              # 运行时配置文件
├── doc/              # 文档（LaTeX）
└── .tmp/             # 临时文件（不提交）
```

### 目录职责说明

| 目录 | 用途 | 是否提交Git |
|------|------|-------------|
| `source/` | 唯一的源代码目录 | ✓ |
| `build/` | 构建配置和Makefile | ✓ |
| `source/cbm*.f90` | 已有的化学机制源码，主模型仍依赖 | ✓ |
| `bin/` | 编译产物 | ✗ |
| `obj/` | 中间编译文件 | ✗ |
| `.tmp/` | 临时工作文件 | ✗ |

当前面向花粉用途移除了 KPP 生成器、独立工具、闲置 POP 模块和专用非花粉案例。
其余非花粉排放、化学、数据同化和拉格朗日模块仍在公共依赖中，未在本轮裁剪。
`silam-toypoint/`、测试程序和共享输送案例继续保留。

## 架构分层与依赖规则

### 分层架构

```
┌─────────────────────────────────────┐
│   应用层 (SILAM)                      │
│   chemistry_manager, dispersion_*    │
│   [业务逻辑]                          │
└──────────────┬──────────────────────┘
               │ 依赖
┌──────────────▼──────────────────────┐
│   库层 (SILJA)                        │
│   fields, grids_geo, globals         │
│   [通用功能]                          │
└──────────────┬──────────────────────┘
               │ 依赖
┌──────────────▼──────────────────────┐
│   基础层                              │
│   natural_constants, max_sizes       │
│   [常量和限制]                        │
└─────────────────────────────────────┘
```

### 依赖规则

#### **允许的依赖方向**

```
✓ SILAM模块 → SILJA模块
✓ SILAM模块 → 基础层（natural_constants等）
✓ SILJA模块 → 基础层
✓ 同层模块之间（需要避免循环依赖）

✗ SILJA模块 → SILAM模块（违反分层原则）
✗ 基础层 → 任何上层模块
```

#### **常用核心依赖**

从源代码分析中提取的最常用模块：
```fortran
! 基础层（几乎所有模块都需要）
USE natural_constants
USE max_sizes_and_limits
USE globals

! SILJA常用模块
USE fields                    ! 场数据结构
USE grids_geo                ! 网格和地理投影
USE field_identifications    ! 场标识和元数据
USE silam_times              ! 时间处理

! SILAM常用模块
USE dispersion_models        ! 主调度器
USE chemistry_manager        ! 化学转化管理
USE field_buffer            ! 场数据缓冲
```

#### **禁止的依赖模式**

1. **循环依赖**
   ```
   ✗ module_a依赖module_b，同时module_b依赖module_a
   ```

2. **越层依赖**
   ```
   ✗ SILJA层直接调用SILAM特定功能
   ```

3. **化学机制交叉依赖**
   ```
   ✗ 不同化学机制（CBM5, CBM7）之间互相依赖
   ```

## 完整目录树

