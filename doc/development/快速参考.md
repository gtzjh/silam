# SILAM开发快速参考卡

## 文件命名

```
SILAM模块：  module_name.silam.mod.f90
SILJA模块：  module_name.silja.mod.f90
主程序：     program_name.f90
化学机制：   cbm5_SOA_Component.f90
```

## 分层依赖规则

```
✓ SILAM → SILJA → 基础层
✗ SILJA → SILAM
✗ 基础层 → 任何上层
```

## 常用编译命令

```bash
# 首次编译
cd source/
make gnu
make

# 增量编译
make

# 清理重编
make clean
make

# 调试版本
make SETUP=gnu_debug
```

## 模块模板

```fortran
module my_module
  ! Description: [功能描述]
  ! Code owner: Name, email
  ! Units: SI

  use globals

  private

  public :: process_data

  subroutine init_module(...)
    ! 实现
  end subroutine init_module
  
end module my_module
```

## Git工作流

```bash
# 创建功能分支
git checkout -b feature/my-feature

# 提交代码
git add source/my_module.silam.mod.f90
git commit -m "Add my feature"

# 推送
git push origin feature/my-feature
```

## 不要提交

```
✗ bin/*              (可执行文件)
✗ obj/**/*           (编译中间文件)
✗ .tmp/**/*          (临时文件)
✗ *.o, *.mod         (编译产物)
```

## 添加新模块流程

1. 确定层次（SILAM/SILJA）
2. 创建文件：`source/module_name.silam.mod.f90`
3. 编写模块骨架
4. 编译验证：`make`
5. 集成到系统
6. 运行测试
7. 提交代码

## 常见问题

**找不到模块文件**
```bash
# 修改 build/options.gnu
INCLUDE = -I$(OBJDIR) -I/usr/lib/.../gfortran-mod-15
```

**栈溢出**
```bash
ulimit -s unlimited
export OMP_STACKSIZE=100M
```

**循环依赖**
- 检查 build/silam_main.rules.full
- 重构提取共同依赖

## 关键文件位置

```
source/silam_main.f90           - 主程序入口
source/dispersion_models.*.f90  - 主调度器
source/chemistry_manager.*.f90  - 化学管理器

```
