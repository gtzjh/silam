## 代码风格约定

### Fortran语法规则

#### **大小写约定**
```fortran
! SILJA风格（旧代码）- 大写关键字
MODULE MyModule
  USE OtherModule
  IMPLICIT NONE
  REAL :: value
END MODULE MyModule

! SILAM风格（新代码）- 小写关键字（推荐）
module my_module
  use other_module
  implicit none
  real :: value
end module my_module
```

**规则**：新代码使用小写，修改旧代码时保持原风格一致。

#### **缩进和格式**
```fortran
! 使用2空格缩进
module example
  implicit none
  
  private
  public :: process_data
  
contains
  
  subroutine process_data(input, output)
    real, dimension(:), intent(in) :: input
    real, dimension(:), intent(out) :: output
    integer :: i
    
    do i = 1, size(input)
      if (input(i) > 0.0) then
        output(i) = sqrt(input(i))
      else
        output(i) = 0.0
      end if
    end do
    
  end subroutine process_data
  
end module example
```

#### **注释规范**
```fortran
! 文件头部注释（必须）
module my_module
  !
  ! Description: [详细描述模块功能]
  !
  ! [可选：算法说明、参考文献]
  !
  ! Code owner: Name, email
  ! Units: SI
  ! Code: ANSI FORTRAN-90
  !

! 重要函数注释（推荐）
  subroutine complex_calculation(param1, param2, result)
    !
    ! Calculates [具体计算内容]
    !
    ! Arguments:
    !   param1 - [说明]
    !   param2 - [说明]
    !   result - [说明]
    !
    ! Method: [如果算法复杂，说明方法]
    !
```

### 命名约定

#### **变量命名**
```fortran
! 推荐的命名风格
integer :: i, j, k                    ! 循环变量
integer :: iStatus, iTime, iSpecies   ! 整数变量（i前缀）
real :: fTemperature, fPressure       ! 浮点变量（f前缀）
logical :: ifValid, ifFound           ! 布尔变量（if前缀）
character(len=fnlen) :: chFileName    ! 字符串（ch前缀）
type(silja_time) :: valid_time        ! 类型实例（下划线分隔）
```

#### **常量命名**
```fortran
! 全大写+下划线
real, parameter :: GAS_CONSTANT_R = 8.314
integer, parameter :: MAX_SPECIES = 1000
```

#### **函数/子程序命名**
```fortran
! 动词开头，下划线分隔
subroutine init_emission_source(...)
subroutine compute_deposition_rate(...)
function get_grid_cell_area(grid, ix, iy) result(area)
```

### 性能考虑

#### **数组操作**
```fortran
! ✓ 推荐：使用数组切片
concentration(1:nx, 1:ny) = concentration(1:nx, 1:ny) * factor

! ✗ 避免：显式循环（除非必要）
do j = 1, ny
  do i = 1, nx
    concentration(i,j) = concentration(i,j) * factor
  end do
end do
```

#### **OpenMP并行**
```fortran
! 在计算密集的循环使用OpenMP
!$OMP PARALLEL DO PRIVATE(i, j)
do j = 1, ny
  do i = 1, nx
    ! 计算...
  end do
end do
!$OMP END PARALLEL DO
```

### 代码文档

**必须文档化的内容**：

### 长期技术结论

架构、接口、构建方式或科学解释有长期变化时，将背景、已确定方案、主要取舍和证据写入对应主题文档。算法结论给出公式与参考来源，验证结论给出输入、方法和适用范围，区分已验证事实与未验证事项。

[AGENTS.md](../../AGENTS.md) 统一维护执行与授权规则，本目录维护技术细节。不建立独立任务日志或 MEMORY，不为每次任务新增流水记录。需要保留的技术结论直接更新相关主题，变更历史由 Git 保存。

项目只维护根目录 `README.md` 和 `.gitignore`。目录概览、使用说明和开发文档索引写入根目录 README，子目录不再创建 README（包括 `00README` 等变体）；本目录继续维护按主题划分的技术文档。忽略规则统一写入根目录 `.gitignore`，使用相对项目根目录的路径限定范围，并保留递归匹配与例外规则。
