# 项目结构与架构

[返回开发文档目录](../../README.md#development)

## 项目概况

SILAM（System for Integrated modeLling of Atmospheric coMposition）是芬兰气象研究所（FMI）开发的大气化学传输模型，用于模拟大气污染物的扩散、转化和沉降。

### 技术栈
- **语言**：Fortran（187个维护的 `.f90` 源文件，另有两个本地生成的版本模块；测试实现使用Fortran 2008子模块）
- **构建系统**：GNU Make
- **保留的编译配置**：GNU (gfortran)、GNU 调试及 GNU MPI
- **外部依赖**：
  - eccodes（GRIB数据格式）
  - NetCDF（科学数据IO）
  - LAPACK/BLAS（线性代数）
  - PROJ（地图投影）
  - BZip2（压缩）
- **化学机制**：保留已有的 KPP 生成源码；本分发不含生成器

### 代码规模统计
```
维护源码：187个 .f90 文件（src/ 155个，tests/ 32个）
测试实现：29个子模块，另有3个独立测试程序
本地生成：src/revision.mod.f90、src/svndiff.mod.f90
生成后本地总数：189个 .f90 文件
模块文件：99个维护的 .mod.f90，另有2个生成的版本模块
  - SILAM模块：52个 (.silam.mod.f90)
  - SILJA模块：32个 (.silja.mod.f90)
  - 其他模块：15个维护文件，另有2个生成文件
程序入口：4个（1个主模型、3个测试程序）
主模型链接：158个对象，含两个版本模块及FISHPACK测试子模块
```

## 架构分层与依赖规则

### 分层架构

以下是历史 SILAM/SILJA 分层的设计定位。当前按功能组织目录，保留既有文件名、模块名、公共接口和 `USE` 关系；目录结构不强制这些层次。现有源码也有跨层依赖，例如 `src/transport/dispersion_models.silja.mod.f90` 使用 `src/assimilation/` 中的 `da_driver` 和 `ensemble_driver`，详见[实际命名模式分析](实际命名模式分析.md)。

```
┌─────────────────────────────────────┐
│   应用层 (SILAM)                      │
│   chemistry_manager, dispersion_*    │
│   [业务逻辑]                          │
└──────────────┬──────────────────────┘
               │ 依赖
┌──────────────▼──────────────────────┐
│   库层 (SILJA)                        │
│   fields, grids_geo, globals         │
│   [通用功能]                          │
└──────────────┬──────────────────────┘
               │ 依赖
┌──────────────▼──────────────────────┐
│   基础层                              │
│   natural_constants, max_sizes       │
│   [常量和限制]                        │
└─────────────────────────────────────┘
```

### 依赖规则

以下规则用于指导新增依赖，不表示现有全部源码已经满足。仅移动文件不改变这些既有关系。

#### **允许的依赖方向**

```
✓ SILAM模块 → SILJA模块
✓ SILAM模块 → 基础层（natural_constants等）
✓ SILJA模块 → 基础层
✓ 同层模块之间（需要避免循环依赖）

✗ SILJA模块 → SILAM模块（违反分层原则）
✗ 基础层 → 任何上层模块
```

#### **常用核心依赖**

从源代码分析中提取的最常用模块：
```fortran
! 基础层（几乎所有模块都需要）
USE natural_constants
USE max_sizes_and_limits
USE globals

! SILJA常用模块
USE fields                    ! 场数据结构
USE grids_geo                ! 网格和地理投影
USE field_identifications    ! 场标识和元数据
USE silam_times              ! 时间处理

! 模型调度和过程管理
USE dispersion_models        ! 主调度器
USE chemistry_manager        ! 化学转化管理
USE field_buffer            ! 场数据缓冲
```

#### **禁止的依赖模式**

1. **循环依赖**
   ```
   ✗ module_a依赖module_b，同时module_b依赖module_a
   ```

2. **越层依赖**
   ```
   ✗ SILJA层直接调用SILAM特定功能
   ```

3. **化学机制交叉依赖**
   ```
   ✗ 不同化学机制（CBM5, CBM7）之间互相依赖
   ```

四个化学机制目录合计 52 个文件：44 个 KPP 求解器及支持文件、四个 SILAM 接口和四个 `chem_dep_cbm*` 适配模块。`numerics/` 中的第三方数值库包含 SILAM 的既有适配，迁移时保留版权说明。

功能目录通过既有 Fortran `USE` 关系协作，没有拆分为独立库。测试实现采用父模块接口和测试子模块，保留私有宿主访问；正常模型只链接FISHPACK参考问题自检子模块，以保留风场初始化行为。其他测试子模块由通用构建入口按父模块依赖选择。`optimisation.silam.mod.f90` 属于 `core/`，负责计时和进度；实际优化求解器 `m1qn3.f90` 和 `lbfgsb.f90` 放在 `numerics/`。
