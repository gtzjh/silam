# 代码开发

## 实现规范

- 保留 SILAM 的 `src/`、`tests/`、`build/` 和 `ini/` 结构。模型源码放在 `src/` 的功能子目录中，测试实现放在 `tests/` 下对应的目录中。
- 不要定义自定义类，也不要从函数返回自定义类的实例。
- 将用户直接提供的参数值视为有效，不要为其添加校验。
- 优先简化逻辑，其次减少模块、函数、分支和参数，最后再减少代码行数。
- 除非用户要求，否则不要引入 Pydantic 或新的命令行接口。
- 编写或修改 Fortran 代码前，加载本地 `fortran` 技能。

## 开发入口

Fortran 工作使用本地 `fortran` 技能；修改旧代码时保持邻近风格。

| 位置 | 职责 |
|---|---|
| `src/core/` | 常量、配置、时间、运行时与并行支持 |
| `src/grid/`、`src/fields/` | 网格、坐标、垂直层与场数据存储 |
| `src/meteo/` | 气象输入、缓存与派生量 |
| `src/transport/` | 扩散调度、输送、沉降与边界条件 |
| `src/emissions/` | 各类排放源 |
| `src/chem/` | 物种、化学、气溶胶、光解及四个 CBM 机制子目录 |
| `src/diagnostics/`、`src/io/` | 诊断、文件格式与输出调度 |
| `src/assimilation/`、`src/numerics/` | 同化、集合、观测、伴随与数值求解 |
| `tests/` | 与生产源码同名的功能目录，含测试子模块和历史测试程序 |
| `build/`、`bin/`、`obj/` | 构建规则与配置、可执行文件、编译中间文件 |
| `ini/`、`daemon/` | 公共运行资源与模板、本地点源案例 |
| `docs/` | `assimilation/` 含 LaTeX 和参考文献源码；无 PDF 构建目标 |

主入口为 [silam_main.f90](../src/silam_main.f90)，主调度器为 [dispersion_models](../src/transport/dispersion_models.silja.mod.f90)，化学管理器为 [chemistry_manager](../src/chem/chemistry_manager.silam.mod.f90)。

生产模块沿用 `<name>.silam.mod.f90`、`<name>.silja.mod.f90`，也存在历史形式。测试子模块使用 `test_<父模块名>_impl.f90`。化学机制保留 `cbm<N>[_strato]_SOA_*` 等形式；当前分发不含生成器。
