# 测试与验证

## 验证要求

- 根据修改的行为及风险选择检查，使用相关的现有检查；需要验证行为时，添加或修改测试。
- 区分环境检查、编译、案例执行和数值回归。每项结果只支持该检查实际验证的内容。
- 进行数值回归时，明确输入、参考输出、变量、单位、指标和容差，并随结果记录代码版本、构建配置和运行设置。
- 如实报告失败和跳过的检查。未完成的检查必须标为“未验证”，不得将案例执行或文件创建当作数值一致的证明。

## 测试

测试子模块通过宿主关联访问父模块的私有类型和状态，父模块保留匹配的 `module subroutine/function` 接口。正常模型仅链接 `tests/numerics/test_fishpack_silam_impl.f90`，用于风场初始化中的参考问题自检。

编译并链接全部测试子模块：

```bash
make -C build -f makefile.generic PROGRAM=silam_main SETUP=gnu
```

输出为 `bin/silam_main.gnu`。它检查测试实现的链接，不自动执行所有测试过程。历史独立程序（`test_modules`、`test_enkf`、`test_perturb`）有已确认的过时接口问题，后两者还缺少运行配置。

### 测试限制

部分测试需要外部数据、模型初始化、交互输入或手工判断；另有空钩子和无数值验收判据的演示：

| 项目 | 限制 |
|------|------|
| `test_modules.f90` | 未声明名称及缺少显式接口 |
| `test_enkf.f90` | 调用签名过时；缺少 `test_enkf.nl` |
| `test_perturb.f90` | 调用签名过时；缺少 `test_perturb.ini` |
| `grids_geo.grid_tst`、`dispersion_models.exec_tests` | 空钩子 |
| `depositions.vd_CAMAERA`、`PrintCamaera` | 无数值验收判据 |
| `photolysis.test_lut_rates_full` | 光解率计算调用被注释 |

[本地点源案例](运行与配置.md#toypoint) 可检查共享输送、输出和通用初始化；它不能证明花粉专属过程正确。
