# 运行与配置

## 运行资源与配置示例

`ini/` 根层保留公共数据、映射、格式说明及 `standard_*_cocktails.ini` 混合物定义。`ini/eccodes/` 保持本地定义的内部目录。控制、源和输出模板位于 `ini/examples/`：

| 目录或资源 | 用途与代表文件 |
|---|---|
| [examples/pollen/](../ini/examples/pollen/) | 桦树、草、橄榄、豚草的控制、源与花粉输出模板 |
| [examples/transport/](../ini/examples/transport/) | 共享输送、平流、拉格朗日、清除及各类源模板 |
| [examples/assimilation/](../ini/examples/assimilation/) | 迭代同化、桦树同化、EnKS、反演与协方差配置 |
| [examples/common/](../ini/examples/common/) | 共用输出、边界及历史 `standard_eulerian.setup` |
| [silam_chemicals_95_OC.dat](../ini/silam_chemicals_95_OC.dat)、[silam_nuclides.dat](../ini/silam_nuclides.dat) | 物质与核素数据库 |
| `optical_properties.dat`、`clim_oh_v3.dat`、`tzindex*.dat` | 光学属性、OH 气候态与时区 |
| `grib_*table*.silam`、`netcdf_name_table.silam` | 气象变量及编码映射 |
| `land_use_features_USGS_Eurasia.dat`、`pollen.materials`、`silja_nuclides.legend` | 土地利用元数据、补充物质定义、核素文件格式说明 |
| `standard_*_cocktails.ini` | 气溶胶、辅助物质、CBM、SOA、火灾及放射性混合物 |

`pollen.materials` 未被现有仓库配置直接引用。土地利用元数据中的历史外部影像路径不表示影像随仓库提供。

### 路径语义

- `STANDARD_SETUP` 内的 `^` 以 `standard_setup_directory` 为基准；未指定时以控制文件所在目录为基准。
- 排放源内的 `^` 以源文件位置为基准。移到子目录的模板用 `^../../` 保持对 `ini/` 公共资源的引用。
- GRIB 名称表通过 `local_definition_path = ^eccodes/definitions` 加载本地定义。

### 输入限制

历史模板保留科学参数和版本差异，未逐个验证可直接运行：

| 示例 | 限制 |
|---|---|
| 多份控制文件 | 气象、植被、物候数据需另行提供 |
| `standard_eulerian.setup` | 引用未提供的数据库文件 |
| 同化配置 | 依赖外部协方差和输出配置 |

保留版本之间有实际差异：两个桦树源文件的 `hsum_cutoff_t` 不同；`grib_name_table_mucape.silam` 以 0.33 缩放 MUCAPE；输出配置的变量和时间平均设置不同。

## 输入路径排查

输入文件找不到时，核对运行工作目录、`standard_setup_directory`、`^` 引用及外部数据。

## 本地点源案例（daemon/）

可执行文件接受一个控制文件参数；不带参数时读取当前目录的 `silam.ini`。隔离运行示例见[本地点源案例](#toypoint)。

`daemon/` 已含 ERA-Interim 气象切片、`src_point.v5`、`output_config.ini` 和 `toypoint_mpi.control`。控制文件使用相对气象和源路径，将输出写入 `output/`，并设置 `standard_setup_directory = ini`。

以下示例从项目根目录开始，将输入副本和新输出放入独立任务目录：

```bash
silam_root="$PWD"
case_dir="$silam_root/.tmp/toypoint-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$case_dir/output"
cp -R daemon/ERA_I-cut "$case_dir/"
cp daemon/toypoint_mpi.control daemon/src_point.v5 daemon/output_config.ini "$case_dir/"
ln -s "$silam_root/ini" "$case_dir/ini"
cd "$case_dir"
"$silam_root/bin/silam.gnu" toypoint_mpi.control > run.log 2>&1
```

可执行文件名应与实际构建配置一致。也可将运行副本中的 `standard_setup_directory` 改为公共 `ini/` 的绝对路径。
